履迹 · 求职进度管理（附带如页简历编辑器）
========================================

【安装】
1. 先把整个压缩包解压到任意文件夹（不要在压缩包里直接双击）。
2. 双击「安装或更新.cmd」。
   · 第一次用的电脑如果没装 Node.js，会问你要不要自动安装（直接回车就行，会弹一次管理员确认）；自动安装不了时会打开下载页：选「LTS」版本，一路下一步装好，再双击一次「安装或更新.cmd」。
   · Windows 可能弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
3. 装好后桌面会出现「履迹」和「如页」两个图标，以后双击图标打开就行。

【更新】
拿到新版本的压缩包后，解压，再双击里面的「安装或更新.cmd」即可。
投递记录、简历、设置都会保留，旧版本会自动备份。当前版本号在 履迹 → 设置 → 关于履迹 里能看到。

【数据在哪】
所有数据都只保存在你自己的电脑上：「文档\求职进度」文件夹，每天自动备份一份。
换电脑时把这个文件夹拷过去，再装一次履迹就行。

【AI 功能（可选）】
模拟面试、识别面试邀请、按 JD 改简历、写话术等功能要用 AI，三选一即可：
· DeepSeek：到 https://platform.deepseek.com 注册并充值几块钱，创建 API 密钥，
  填到 履迹 → 设置 → AI 助手 → DeepSeek 密钥。最快最便宜。
· 电脑上装了 Claude Code 或 Codex 命令行并已登录的，可以直接用，还能联网搜索。
不配置 AI 也能正常使用其他所有功能。

【Boss直聘 / 牛客网 自动记录（可选）】
装一个浏览器小扩展后，在 Boss直聘 网页版点「立即沟通」、在牛客网点「立即申请」并确认，就会自动记到履迹，聊天里收到面试邀请也会交给履迹建日程。
1. 履迹 → 设置 → 「投递自动记录」→ 点「打开扩展文件夹」。
2. Edge 地址栏输入 edge://extensions（Chrome 是 chrome://extensions），打开「开发人员模式」。
3. 点「加载解压缩的扩展」，选刚才打开的 extension 文件夹。
4. 在同一个浏览器里打开一次履迹，扩展就会自动连上。
扩展只读取你正在看的页面，不会替你点按钮或投递。只对网页版有效，手机 App 上的操作记不到。
【卸载】
双击「卸载.cmd」（或开始菜单 → 履迹 → 卸载履迹）。数据文件夹不会被删除。
