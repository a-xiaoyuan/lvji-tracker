**名称**（来自扩展本身，不用填）：履迹助手 · 投递自动记录

**简短说明**（Short description）：

> 在 Boss直聘、牛客网、智联招聘、前程无忧投递时，自动把岗位记到你电脑上的「履迹」求职记录里；网申页面还能一键填空字段。

**详细说明**（Description）：

> 履迹助手是开源求职记录软件「履迹」的配套扩展。
>
> 你在 Boss直聘 点「立即沟通」、在牛客网 / 智联招聘 / 前程无忧投递成功时，它会把公司、岗位、薪资、地点和岗位描述自动记进履迹，并标记为「已投递」。在 Boss直聘 的聊天里收到面试邀请时，它会把邀请交给履迹识别成日程；HR 回了消息，会在履迹里给这家记一笔「HR 已回复」。
>
> 在公司官网的网申页面，点扩展弹窗里的「把我的档案填进这个网申页」，它会按你在履迹里填的档案填上空着的输入框，已经填了的不动。
>
> · 不会替你点击任何按钮，不会自动发消息、自动投递或自动提交网申
> · 招聘网站上只读页面；只有你点了填表按钮的那个页面会被填入内容
> · 只和你自己电脑上的履迹（127.0.0.1）通信，不连接任何其他服务器
> · 不收集、不上传任何数据，没有统计和广告
> · 页面改版导致识别不了时，会在扩展弹窗和履迹的设置页里显示自检记录，方便排查
>
> 使用前需要先安装履迹（免费、开源）：https://github.com/a-xiaoyuan/lvji-tracker
> 打开一次履迹，扩展就会自动和它连上。

## 5. 权限说明（审核时会问，填在「Notes for certification」或对应权限的说明里）

- `activeTab`、`scripting`：只在用户点击弹窗里的「把我的档案填进这个网申页」按钮时，在当前标签页运行一次填表脚本（填空字段、不提交）。不会在后台访问任何页面。
- `storage`：保存扩展自己的设置（是否自动记录）、与本机履迹配对用的访问密钥、最近记录的 15 条岗位名和自检记录。只存在浏览器本地。
- `http://127.0.0.1:47321/*`：这是用户自己电脑上的履迹程序。扩展只把识别到的岗位信息发到这里，不访问其他网址。
- 内容脚本 `zhipin.com`、`nowcoder.com`、`zhaopin.com`、`51job.com`：读取岗位页上的公司、岗位、薪资、地点、岗位描述，以及（仅 Boss直聘）聊天里的面试邀请文字和 HR 是否回复了消息。不修改页面内容（只在右下角显示一个小提示），不点击任何按钮。
- 内容脚本 `127.0.0.1:47321/jobs/`：从本机的履迹页面取访问密钥完成配对。

## 6. 给审核员的说明（Notes for certification）

> This extension is a companion to Lvji (履迹), an open-source, local-only job application tracker (https://github.com/a-xiaoyuan/lvji-tracker). It only reads job details on zhipin.com / nowcoder.com / zhaopin.com / 51job.com when the user clicks the site's own apply/chat button, and sends them to the Lvji app running on the user's own computer at 127.0.0.1:47321. When the user clicks "fill this application form" in the popup, it uses activeTab + scripting to fill empty fields on that one page from the user's own profile stored in Lvji; it never submits the form. It never clicks, never sends messages, never contacts any remote server, and collects no data.
>
> To test without installing Lvji: open the popup — it shows "履迹没在运行" (Lvji not running) and the extension does nothing else. To test fully: download the installer zip from the GitHub Releases page, run 安装或更新.cmd, then open any job page on zhipin.com.
